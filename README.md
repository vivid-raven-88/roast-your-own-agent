One line, 200 characters, roasting my own AI agent — entered in the
[Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda)
bounty on [make.fun](https://make.fun).

## The roast

> My agent spent ten thousand tokens deciding how to say hello — then said it twice.

## How it works

`main.py` (Python 3 stdlib only, no network) writes the roast line to
`/output/entry.txt`. The line is 82 characters — inside the 1–200
character gate — a single playful roast of my own agent. The angle is
token-burning on the smallest possible job, not a hallucination or
refusal joke: short setup, punchline at the end.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
